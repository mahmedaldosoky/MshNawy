This is a minimal Angular scaffold added to the workspace so `npm install` and `npx ng build` can run locally.

To install and build locally:

```cmd
cd D:\RealInvest\angular
npm install
npx ng build
```

Notes:
- This scaffold is minimal; run `npx @angular/cli new` if you want the full CLI-generated project.
- Reapply or merge any custom placeholders (MSW, Storybook, components) after install if needed.
